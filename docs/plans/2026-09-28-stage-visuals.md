# 第二阶段：完整作品画面与舞台感视觉动效

用户批准的实现方案；基线 bf4bcba，沿用 portfolio-media-optimization 本地分支。

## Global Constraints

保留黑红风格、数字人形象、每页 8 项和 4/2/1 列布局。作品完整显示，统一 16:9、object-fit: contain、必要时深色留边；画面无全局滤镜或放大裁切。第一阶段资源、数据和管理接口不变：20 秒预览（短片全长）、手机 720p、桌面可见及上下 120px 全部同时播放。

正文默认可见，禁用 JavaScript 或动画能力缺失时阅读、播放与联系可用。减少动态效果即时结束装饰动画；页面隐藏后结束且不重播。保留原生滚动、原生视频控制条、键盘焦点和背景音乐默认关闭。只本地提交，不合并、推送或发布；案例、字体资源、SEO 留后续阶段。

## Task 1: 页面视觉、动效与真实浏览器回归

负责 index.html 和相关 tests；不修改资产与作品目录。先写真实行为测试，记录正确的红灯，再实现并验证、提交。

- Hero 桌面 540–580px，手机 450–480px，窄屏内容允许自动增高。保留标题，两段简介合并为“3D、动画与剪辑，从脚本前期到多平台交付。”，英文“3D, animation and editing, from script development to delivery across platforms.”。移除重复签名段与相应不再使用的语言赋值。
- 全部作品和 noscript 卡片采用 16:9 画框；封面和预览 contain、原始色彩、无缩放裁切，删除前三张比例与文字差异。同一行媒体及文字起点对齐，完整说明允许自然换行。
- 红色交互统一；按钮圆角 12px、卡片 16px、面板 24px（播放控制圆形图标与数字人合成不强制改变形状）。标题 >=16px、分类 >=13px、说明 >=14px；普通文字与实际底色对比 >=4.5:1。清除公共页残留金色声明，避免再增加一套大面积覆盖样式。
- CSS + IntersectionObserver + Web Animations API；无需新依赖。标题行内遮罩上移 48px、每行 650ms，间隔 100ms；人物横移 24px淡入 900ms；简介和按钮随后，桌面全部 <=1100ms。手机位移减半、总时长 <=850ms。首屏仅初次显示执行；直接访问下方锚点立即显示对应内容。
- 章节标题上移 24px/500ms；卡片上移 20px/450ms，同一行间隔50ms，仅首次进入视窗。目录加载、语言切换、分页均不重复启动整页入场；快速滚动不会留下隐藏内容。无需以私有测试字段暴露动画实现。
- 桌面 hover 卡片上移2px、红框240ms；键盘焦点清楚；触屏不依赖 hover，画面不放大。
- 播放器打开背景淡入、面板 .98→1、220ms；关闭140ms。关闭即时清理媒体并恢复焦点/背景，残留退出层不截获操作；快速重新打开取消旧动画和旧完成回调。原有播放事件/重试会话不受动画影响。
- 正文默认显示，只在动画真实启动时短暂动效；减少动态效果、页面隐藏、API缺失或异常时取消/结束到可见基态。运行中改变设置也立即生效，无动画或旧完成回调导致状态回退。
- 增加真实浏览器测试，验证布局与完整画面、动态设置、锚点、快速开关等；只新增必要测试，既有签名段检查按已批准删除更新。
- 验收视口：1440x900、820x950、390x844、320x760，中英无横向溢出、按钮可见。1440首屏至少80px作品图像，390至少60px。纯静态与无JS仍完整可用。

根代理负责拍摄前后截图、固定文档、最终独立验证和复核。已有 node serve.js 预览在127.0.0.1:3000，请复用。

## Task 2: 验证、截图、文档和交付

根代理对 Task 1 完成定向审查，执行新浏览器回归及第一阶段回归、静态页面和语法检查；检查桌面/手机前后截图和比例。更新产品需求、软件架构、当前进度，并制作截图说明文档。任务完成后提交并进行一次全阶段审查；保留分支和预览，不推送。

风险：动画生命周期不能干扰播放器会话或焦点；目录初始/最终渲染不能重复动画；窄屏英文排版可能需要自然增高，优先可读与可操作。

# 当代影像工作室整体重做

设计日期：2026-10-07。完成日期：2026-10-08。用户授权整体重做并选择「当代影像工作室」。

## 目标与设计

把 Highstrith / 橘小桔的完整作品组织成可直接观看、分类浏览的影像作品集。原数据保留 15 部，公开展示 14 部。首页突出真实影像，作品、作者与联系形成自然纵向路径。采用纸白 #f4f4f0、墨黑 #171918、次级灰 #6b706d、线条 #d8dbd5、橘色 #e46740；按用户反馈使用克制的常规字号与字重（首页最多 44px、章节最多 36px），以作品和留白承载识别度。字体使用系统 Helvetica Neue / Arial / PingFang SC，避免字体网络依赖。

首屏由简明定位与大幅精选作品组成，五部代表作可手动切换和播放，当前按用户指定替换为《重置日》、Prove It、《AI患者》、Two Seconds、《AI 之后》，后续新增仍优先进入首位。全部作品直接展示，提供全部、叙事短片、三维与动画、剪辑与视觉分类及标题/描述搜索，按日期倒序。作者区保留数字人肖像与真实创作定位，联系区突出邮箱和三枚二维码、哔哩哔哩入口。手机布局自然纵向流动，不以横滚或强制动画阻挡内容。

管理页统一品牌，桌面左编辑器右作品库；保留新增、编辑、封面生成、媒体限制、删除和双语能力。公开 GitHub Pages 依旧只展示，本地 Node 服务管理内容。

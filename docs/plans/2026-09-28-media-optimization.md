# 第一阶段媒体与访问体验实现计划

用户已授权实施；工作区 `site-portfolio-upgrade`，分支 `portfolio-media-optimization`，基线 `fbb7da5`。不推送、不发布、不修改原视频内容。

## Global Constraints

- 保留黑红视觉、作品顺序、8 项分页及 4/2/1 列布局。
- 桌面可见及上下 120px 内全部卡片可同时播放轻量预览，没有并发数量限制；手机和减少动态效果只显示封面，手动播放不受限制。
- 作品数据新增可选 `previewVideo`、`webVideo`，复用 `mobileVideo`，`video` 保留原文件。衍生目录 `assets/optimized/<work-id>/`，内容与配置摘要命名。
- 前端、本地服务和管理页保留字段；编辑文案不能丢失资源，上传作品替换原视频时清空旧衍生引用；内置媒体保持锁定。
- 单作品生成失败保留该作品原有资源；原文件 SHA-256 不变。GitHub Pages 仍为静态站。
- 文本修改使用 apply_patch；真实行为测试先失败，再实现。每个独立完成改动集提交，仅暂存自己负责文件。

## Task 1: 本地服务与管理页的资源接口兼容

拥有 `serve.js`、`admin.html` 和新增 `tests/works-api-integration.mjs`；不编辑其它文件，不更新目录真实作品，不生成媒体。先依次阅读 AGENTS.md、产品需求.md、软件架构.md、当前进度.md。

- normalize、GET/POST/PUT 支持 `previewVideo`、`webVideo`，缺失字段默认为空；已有 `mobileVideo` 可指向 optimized 目录。
- 原视频与封面现有 uploads 校验保持；衍生资源允许 uploads 或 optimized 目录，校验真实路径包含关系，不能越过对应目录。
- PUT 只修改文本保留所有媒体；上传作品替换 video 时必须清空 previewVideo、webVideo、mobileVideo（不信任旧字段）；保留内置作品媒体变更 403。
- 替换/删除只清理不再被任何作品引用的上传或 optimized 文件，引用检查覆盖原视频、封面和全部衍生字段。
- 管理页 normalize 与提交保留新字段；替换原视频清空衍生字段；悬浮优先轻量预览，手动打开优先 webVideo，回退原 video。
- 真实 HTTP 测试在临时副本服务中执行，不修改当前目录：字段读写与文字编辑保留、替换失效、共享资源不误删、内置限制、目录逃逸拒绝。先记录正确失败，再实现并提交。
- 不派生子代理；完整报告写到对应 task-1-report.md，只返回状态、提交、测试摘要与风险。

## Task 2: 媒体生成与资源验证

- 固定 ffmpeg-static@5.3.0 安装在独立工具缓存；支持 FFMPEG_PATH。生成脚本无网站运行依赖。
- 按用户最新修正，13 项生成预览与手机版；预览默认 20 秒（原片不足 20 秒时使用全片）、无声、长边 <=960、帧率 <=30、体积 <=2MiB，起点 min(20% 时长, max(0, 时长-20))。
- 简化为固定配置与一个可重复运行命令，不新增后台自动转码、配置界面或任务队列。
- 手机 H.264/yuv420p、AAC、faststart，横版 <=1280x720、竖版 <=720x1280、不放大、保持比例，码率 <=3Mbps。完整桌面仅索引末尾时无损 remux，其他使用原文件。
- 临时输出验证后使用摘要 URL 并更新目录；支持重复运行跳过、独立作品失败隔离。生成完成不删除原素材。
- 真实短视频 fixture 先测约束、失败隔离、重复运行与原文件不变，再实现。全量核对解码、索引、尺寸、体积和 SHA-256。

## Task 3: 公开页播放、状态与渐进显示

- 预览与完整版数据源分离，手机版优先 mobileVideo，桌面优先 webVideo，缺失回退 video；无 previewVideo 只显示封面。
- 匹配条件随视口与媒体查询变动；页面隐藏和播放器打开时暂停预览；恢复重新同步。
- 加载/缓冲/点击播放/失败/重试状态；重试同一完整版；每次打开关闭清理事件与计时器。原生控件、键盘焦点、方向处理保持。
- 正文默认可见，脚本就绪后仅对屏幕下方内容启用进入动画；无 JS 显示所有作品封面、名称及完整版链接。自动同步完整快照和 noscript 目录，数据为单一源。
- 修正中英作品区文案，切换语言不覆盖。
- 浏览器真实网络与状态测试先失败，后实现；覆盖并发预览、手机版来源、404/retry/慢加载/拒绝播放/快速切换、减少动态效果、静态和 file 回退、无 JS、分页布局。

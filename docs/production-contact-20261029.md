## 实现与复用

开工前复查 [PhotoSwipe](https://github.com/dimsemenov/PhotoSwipe) 的缩略图与图片说明方式。本站已有原生dialog、双语及按需加载，继续沿用现有代码，不复制第三方源码、不新增运行依赖。

步骤：核对真实项目素材及绑定 → 选取不同角色、空间与景别 → 原件逐字节归档、生成WebP → 更新数量与分组行为测试并确认旧页面失败 → 首页9张／独立页15张接触印样 → 中英、手机、无脚本、弹窗与性能验证 → 更新固定文档与本地提交。主要风险是原件仅留在临时目录、图片增加造成首屏传输上涨，以及多图后的导航／数量失配，分别用持久归档、原有延迟图源和真实浏览器回归验证。

展示保留白色基底和克制字号：首页项目说明在左，三列小图在右；独立页分资产6张、分镜5张、工作台4张，组内三列，手机两列。完整画面不裁切，点击看大图。无新筛选状态或自动轮播，五部精选与作品目录数据保持。

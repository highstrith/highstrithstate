# 联系区整行反色

2026-10-30，参考用户提供的Hello World联系区截图：整行随悬停切换背景与字色。开工前检索并评估了[开源作品集的CSS悬停示例](https://github.com/ye-soul/portfolio/blob/main/index.html)，其交互主要是文本和标签变色；本站保留原DOM与实际功能，用独立CSS实现整行反色，无需引入模板、动效库或复制外部源码／素材。

执行方案：仅新增`assets/contact-rows.css`并由首页引用，把邮箱组和四个社交入口排为横向行，180ms同步过渡墨黑底／纸白字。保留原有字号约束及所有真实联系信息，电话号码／微信号放在邮箱下方。风险是原有文字颜色覆盖反色、邮箱和复制按钮挤压、触屏悬停残留；以局部高优先级选择器、手机换行、精细指针媒体查询和真实操作测试验证。

- 社交行24px标题，右侧保留扫码／打开主页提示；不引入参考图的超大字、序号或装饰箭头。
- 邮箱链接和复制按钮同属一个视觉行但保持独立语义，原复制成功／失败逻辑不改。邮箱行与社交行同宽，修正继承`justify-content:space-between`导致隐式Grid收缩为内容宽度的问题。
- 桌面hover与键盘focus-visible采用同样颜色；没有依赖focus-within的鼠标常亮状态。触屏直接点击，二维码对话框与返回焦点延续原逻辑。
- 320／390px邮箱和复制按钮可换行，最小点击高度44px；社交行至少76px。减少动态停用颜色过渡，仍保留即时状态。

验证：`python3 tests/contact-rows-smoke.py -v` 3项通过（旧版宽度断言失败，新版通过）；既有`StudioRedesign`二维码预览／点击和手机双语2项、`ExhibitionUpgrade`邮箱复制成功／失败1项通过，Pages实际打包1项和Git空白检查通过。桌面视觉检查见`contact-rows-20261030/desktop.png`。仅验证本机Chrome及触屏模拟，未验证真实iOS／安卓和Safari。仅本地提交，未发布。

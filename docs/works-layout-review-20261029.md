# 作品集排版修订

用户认为作品集仍显奇怪，要求改好后由其审核，确认OK再push。本轮只修改本地作品列表展示，保留五个精选与全部20部公开作品、播放和评论、15张制作记录及其原件。

## 设计与复用

初版7／5列跨度、92／48px顶部偏移与竖片300px限宽居中叠加，造成不齐的起点、很宽的空洞和被竖片撑高的整行。横片分类在右、竖片分类在下，也缺少统一阅读顺序。

开工前评估 [JustifiedGalleries](https://github.com/plymouthvan/JustifiedGalleries) 按原始比例等高排列的方式。本站已有比例、筛选和媒体调度，沿用原生DOM与CSS实现行分配，不复制该项目代码、不新增依赖。

将画廊改成等高行，宽窄来自素材真实比例；同行顶部与画面高度一致，目标250／210px、最大300px，末行左对齐不过度拉大。标题20px、分类10px、简介12px两行统一左对齐。手机竖片使用画面与文字并排，画面宽度最多190px，保持完整比例。

步骤：定位空洞／错位并记录旧布局 → 新增真实布局断言并复现三项失败 → 按可见顺序计算行宽、调整caption与手机竖片 → 校正图片sizes及尺寸变化 → 筛选、播放、评论、导航、性能与静态打包验证 → 提供截图及本地预览供用户审核。

## 实现边界

主要修改`assets/exhibition.css`、`assets/studio.js`，制作动效仅增加重排事件刷新。自适应按宽度变化触发，异步海报尺寸修正合并到rAF。保留原节点，切目录不重新渲染或改变选中筛选；全部数据、顺序、原片、封面和Hero保持。

当前版本等待用户视觉审核。未经新的明确确认不push、不发布。

- 新作品布局3项先复现失败后通过：桌面同行对齐／原比例／300px高度上限、筛选与目录切换及缩窗顺序、320／390／600／820／1440／1920中英文和手机竖片图文并排。
- 画廊10项、制作记录17项、评论8项、首屏图片预算1项、Node实际打包／媒体／目录同步8项通过。脚本语法与Git空白检查通过。
- 桌面图墙、首屏与手机截图人工查看。审核图隐藏悬浮导航并移开指针，避免截图中插入粘性导航或悬停文案。截图保存在 `docs/works-layout-review-20261029/`。
- 独立复核未发现比例／排序／响应式阻断问题；复核指出目录模式可能沿用较大的画廊sizes，已改成按目录媒体实际宽度更新。

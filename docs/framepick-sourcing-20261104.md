# 片源渠道：X / YouTube / 影展黑客松

2026-11-04

11-02 那轮试跑把 X 和 YouTube 暂缓了，优先抖音、小红书、B 站。这份补回暂缓的两处，加上影展与黑客松，共四类入口。

## 结论

1. **影展和黑客松命中率最高、频率最低。** 一年几个窗口，一次能捞十几部，质量有评审背书。适合定片库骨架，不适合做周更。
2. **YouTube 供给最稳。** 作者频道 + 两个聚合站，每周稳定出 2–3 部，是周更主力。
3. **X 是片子最早出现的地方。** 爆款先在 X 上跑，两三个月后才上 YouTube。适合抢「首次被本站收录」，但站内搜索 11-02 三次连续报错，只能靠作者名单追踪。
4. **顺序**：影展榜单搭骨架 → YouTube 作者频道做周更 → X 名单抢先。

## 五、选片规则第 1 条要改

现在写的是「时长 8 分钟以上，有完整叙事」。按这条，Runway 2026 十部获奖片只能进两部。八分钟的初衷是筛掉氛围片，但长度不等于叙事——《POSTMAN》7 分钟讲完了一个完整的送信故事，《THE WELL》5 分半有案子、有嫌疑、有反转。

改成两档：

- **长片档**：8 分钟以上，每期 1–2 部，用来做「这周的主菜」
- **短片档**：5 分钟以上且满足「有主角目标 + 有阻碍 + 有收束」，每期 2–3 部

其余三条（美术方向、声音处理、30 天内或首次收录）不动。这样一期 5 部里既有 17 分钟的《合龙》，也放得进 7 分钟的《POSTMAN》，不会因为时长把好片挡在门外。

| 时间 | 动作 | 产出 |

## 七、一个提醒

Escape.ai 的 Neo Cinema、SHAIKE.AI 的 TOP CREATOR 榜、aifilmhistory 的 372 条编年，已经在做「AI 短片编选」这件事，而且做得比现在这个站深——Escape 有创作者入驻和策展合集，SHAIKE 有榜单和作者主页。

差异不在筛片本身，在三件事：中文语境（国内创作者和国内观众都不看英文站）、每周一份固定更新、每部写清楚为什么。前两件靠执行，第三件靠判断力。所以文案要往「判断」写，不是往「推荐」写——「这部解决了一个什么问题」，而不是「这部很好看」。

# 制作记录返回与动效

用户反馈制作页点入后难返回，图墙缺少醒目的互动。本轮目标是完整返回链和可感知的浏览反馈，保持15张记录／首页9张、原件归档和五部精选布局。

## 原因与实现

- 独立页明确的返回入口原来只有页脚，顶部作品导航也不会直接回制作区。新增顶部站内返回链接，保持当前语言与`#in-progress`。
- 首页目录异步加载会改变下方制作区位置，原生初始hash滚动先发生，导致返回后落点错位。目录排版完成再校正目标章节。
- 原图dialog原来不参与浏览器历史。新增共享history控制，按钮／Esc／背景走同一关闭入口，由popstate关闭；Forward恢复关闭前所选图片，清理仍使用原有焦点／音乐／滚动锁机制。语言切换保留history.state，避免删除图片entry。
- 原制作页未接入滚动动画，只有背景色悬停。增加GSAP分组错峰入场、桌面微倾斜和弹性回位、dialog开图与图片切换；减少动态自动回退静态。内容默认可见，动效脚本缺失不影响查看或返回。

实施：先补真实返回链／动效测试并复现失败 → 顶部返回和图集文字入口 → 浏览器历史、快速开关与前进恢复 → 本地动效库与分层动画 → 手机、静态回退、打包、性能及界面验证 → 固定文档与本地提交。

## 复用与许可

开工前检查 [GSAP官方仓库](https://github.com/greensock/GSAP) 和 [ScrollTrigger文档](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)。使用官方`3.15.0`标签发行文件，保留版权、作者与[Standard License](https://gsap.com/standard-license/)链接，不修改发行代码，静态服务本地文件。

## 验证

- 制作记录17项通过：顶部返回、准确锚点、双语、Back关闭／Forward恢复所选图片、重复Esc、快速开关、GSAP响应与减少动态、库故障静态回退，以及原有15图／9图、file和无脚本。
- Forward恢复图片的两项回归先复现错误（始终回第1张）再修复；entry保存可变当前索引。原生dialog阻止点击背后语言开关，测试按真实操作在关闭后切换语言。
- 画廊10项、Node打包／媒体／目录同步8项、冷启动图片预算1项通过；图片传输仍为137,284 B，主封面960px。脚本语法及Git空白检查通过。
- 桌面与手机截图、返回链接位置已检查。截图保存在 `docs/production-motion-20261029/`。本轮保留15份原件和30份衍生，未修改制作资料，未push或发布。

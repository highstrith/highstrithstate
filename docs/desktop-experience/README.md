# 桌面作品集重设计预览

使用 `node serve.js`，访问 `http://127.0.0.1:3000/`。桌面增强在宽度至少 1024px 且有精细指针时启用；系统减少动态效果会显示纵向作品列表。

- `before-hero.png`：原版 1440×900 首屏。
- `after-hero.png`：全屏数字人首屏。
- `after-stage.png`、`after-stage-4.png`：横向主展不同位置。
- `after-catalogue.png`：全部 14 部作品目录。
- `after-about.png`：作者介绍区。
- `after-contact.png`：联系区。
- `desktop-walkthrough.webm`：首屏、主展跳转、目录和联系区的操作录屏。
- `typography-stage-cn.png`、`typography-stage-en.png`：排版修正后的 1280×720 中文与 1440×900 英文主展，文字区与控制区独立留白。

截图与录屏来自本地 Chromium；线上站点尚未更新。

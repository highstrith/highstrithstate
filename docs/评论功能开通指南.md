# 作品评论功能开通指南

这份指南面向不做技术的你。照着做完，网站上就会出现「评论」按钮，访客不用注册登录、填个昵称就能留言。

整个过程分四步，你只需要做前三步（都在腾讯云上），第四步交给我。

---

## 先看这里：你需要准备什么

| 项目 | 说明 |
| --- | --- |
| 一个腾讯云账号 | 没有就现注册，微信或 QQ 一分钟能注册完 |
| 一张银行卡 | 腾讯云需要验证，**不会自动扣费**，只是验证资质 |
| 每月约 19.9 元 | 云开发「个人版」套餐价，以腾讯云控制台显示为准。**免费体验版不能用**，原因见下 |

### 为什么不能用免费版

免费体验版有两处硬限制，会直接导致评论发不出来：

1. **不能添加跨域域名白名单。** 你的网站在 GitHub 上，和腾讯云不是同一个地址，浏览器会拦截请求。
2. **云函数只能用 3 秒**。评论写入偶尔会超过，表现为「转圈很久然后失败」。

所以必须买个人版套餐。**只买一个月的套餐就够**，之后如果想停用或不续费，网站会照常显示，评论入口会自动隐藏。

## 第一步：买一个云开发环境

1. 打开 <https://buy.cloud.tencent.com/lowcode?buyType=tcb>
2. 登录腾讯云，按提示购买 **个人版套餐**（约 19.9 元/月）。
3. 创建环境时注意两点：
   - 数据库必须选 **「云数据库」**，选错要重开环境。
   - 地域选 **「上海」**（保持默认即可）。选其他地域需要额外配置，容易出错。
4. 提交后等待环境就绪，大概 1～2 分钟。

**记下环境 ID**：环境创建完成后，把鼠标悬停在左上角的环境名称上，会显示类似 `highstrith-comments-abc123xyz` 的字符串。这个就是后面要填进网站的「环境 ID」，不含 `https://`。

---

## 第二步：打开三个开关

进入 <https://tcb.cloud.tencent.com/dev>，确认左上角环境是你刚创建的那个，然后依次完成三件事。

### 2.1 允许匿名登录

路径：**身份认证 → 配置 → 登录方式 → 打开「允许匿名登入」**

这一步是让访客不用注册就能留言的关键开关，**必须打开**。

### 2.2 添加跨域白名单

路径：**HTTP 网关 → 跨域设置 → 添加跨域域名**

填入（只填域名，不要加路径和斜杠）：

```
https://highstrith.github.io
```

> 免费体验版看不到这个入口，这正是前面让你买个人版的原因。

### 2.3 修改云函数调用权限

路径：**云函数/托管 → 云函数 → 函数管理**

这一步要在新建云函数**之后**再做。顺序：先做第三步创建函数，回来再做 2.3。

---

## 第三步：创建留言用的云函数

路径：**云函数/托管 → 云函数 → 函数管理 → 新建云函数**

按下面填，一共只改三个地方：

1. **创建方式**：选「通过模板创建」→「Node.js Hello World」
2. **函数名称**：填 `twikoo`
3. **运行时**：保持模板默认的 **Node.js 20.19**
   - 不要选 Node.js 24.11（公测），官方实测装不上依赖
   - 不要选 Node.js 18.15，依赖要求 20.19 以上

创建后进入函数代码编辑页，把里面默认的内容替换掉：

**index.js** 全选删除，粘上：

```js
exports.main = require("twikoo-func").main;
```

**package.json** 全选删除，粘上：

```json
{
  "dependencies": {
    "twikoo-func": "2.0.13"
  }
}
```

> 这里写死 `2.0.13` 是为了保证云端和网站用的是同一个版本。写成 `"latest"` 也能用，但将来云端自动升级后可能和网站不一致，出问题时不好排查。

然后点「创建」，等状态变成 **「正常」**。

### 回头补第二步的 2.3

回到 **云函数 → 函数管理**，找到刚建的 `twikoo` 函数，点「鉴权设置」右边的 `⋮`，选择 **「权限控制（legacy）」**，填入：

```json
{
  "*": {
    "invoke": "auth != null"
  }
}
```

保存。这一步是允许带匿名身份的访客调用云函数。

---

## 第四步：把环境 ID 填进网站（交给我）

把第一步记下的**环境 ID** 发给我，例如 `highstrith-comments-abc123xyz`。

我会做三件事：

1. 把 ID 填进网站的评论配置文件 `assets/comment-config.js`
2. 跑一遍完整测试，确认作品目录、播放、筛选都正常
3. 提交并发布，网站更新后评论功能就上线了

---

## 上线后怎么用

- 每部作品下方会有一行小字「评论」，右边带数字表示已有几条。
- 点一下展开留言区，再点收起。同一时间只展开一部作品。
- 访客不需要注册登录，填昵称（可选填邮箱和网站）就能留言。
- 想删掉某条评论，在评论右下角的「管理」里登录后删除，密码在你创建云函数后可在 Twikoo 后台设置。

### 你自己怎么删评论

评论框里点 **管理**，用你设置的管理密码登录，可以删评论、改配置、导入导出数据。管理面板入口只有知道密码的人能看到。

## 出问题时怎么办

| 现象 | 多半原因 |
| --- | --- |
| 页面上根本没有「评论」按钮 | 环境 ID 没填，或填错 |
| 点了按钮，提示加载不出来 | 云函数没部署成功，或跨域白名单没加 |
| 能看到留言框但发不出去 | 匿名登录没打开，或云函数权限没改成 `auth != null` |
| 发表评论转圈很久后失败 | 云函数还是 3 秒超时，确认买的是个人版而不是体验版 |
| 评论条数不对 | 云函数和网站版本不一致，确认 `package.json` 里是 `2.0.13` |

排查时先看腾讯云控制台的 **云函数 → 日志**，报错原因都在那里。

---

## 不想要了怎么办

直接在腾讯云控制台停用或销毁环境即可。网站不会坏——评论服务连不上时，「评论」按钮会自动隐藏，作品目录、播放、搜索一切照旧。

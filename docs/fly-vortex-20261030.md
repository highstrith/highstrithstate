# 精选放映：螺旋穿行

日期：2026-10-30。用户确认参考 Hello World 的 (03) WORK，优化现有精选放映区，仅本地预览。

## 参考与复用评估

- 实际访问 [Hello World](https://helloworlddsgn.com/#work)，核对其 WORK 的卡片螺旋、沿轴推进及相机旋转机制。上一版只有固定XY与缩放，不能形成绕标题穿行。
- 开工前检索并评估 [DAY_018](https://github.com/thounny/DAY_018)：GSAP／ScrollTrigger 的卡片翻面更偏向正反面切换，和本次螺旋路径不匹配，未复制其代码或资产。
- 评估 [Three.js](https://github.com/mrdoob/three.js)（MIT）：适合参考站的WebGL场景与后处理，但本次只有20张平面封面，使用原生CSS透视即可完成。未引入该依赖，也未复制参考站源码、图片、字体或模型。

## 执行方案与实现

目标是把现有精选放映的直线飞入变为绕标题旋转的纵深穿行。涉及独立fly-forward CSS／JS、首页段落和资源版本、真实浏览器回归及项目文档。先验证旧版无极角变化，再改布局和运动，最后检查反向滚动、断点、双语、目录与播放。主要风险是透视轴偏移、减少动态后残留隐藏状态、提前下载过多图片；均用实际浏览器核对。

- 340vh滚动区内，100svh舞台保持粘性；中间标题、正文和全部作品入口保持正常朝向。
- 按归一化滚动位置p计算统一转角1.9p弧度；第i张图使用0.83i的错位极角和320px的深度间隔。相机推进和极角同步变化，产生旋转穿行；近处图片从边缘出画，远处逐渐显现。
- 使用真实目录最多20张封面与标题，沿用排序、隐藏规则和翻译，不维护第二份作品数据。装饰图层在桌面不进入键盘／屏幕阅读顺序；查看全部作品入口始终可操作。
- 800px及以下、系统减少动态采用手动横向图带。没有JS时段落保持短小并提供全部作品链接，下方完整无脚本目录仍在。
- 使用现有以480px为主的轻量封面，原生lazy加载；不创建额外video。调度只在可见且需要追赶滚动位置时继续，离屏／后台取消。
- 手机横滚的scroll-snap不会继承到桌面：桌面图层overflow:clip并禁用snap，切换模式清理变换与滚动位置。标题36px／28px，不改变白色V2主题。

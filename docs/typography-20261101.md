# 两站排版与字号层级修订

日期：2026-11-01

用户明确撤销此前“不能用大字”的约束，并确认作品集主站与独立片单两边都要调整。产品需求中旧的首页44px、区块36px、手机28–30px硬性上限已经移除，历史进度中的旧规则不再生效。

## 设计判断与改动

问题不只在字体：主站的介绍、作品说明和截图说明原先大量使用10–13px，区块标题与正文之间的比例偏弱；片单虽已使用大字，但薄宋体标题与9–13px小字、左半页内容堆叠，导致首屏重心不平衡。

- 作品集保留原有系统黑体、纸白／炭黑主题与橘色强调。首屏标题响应式40–80px，字重550；区块标题32–52px，导演台32–50px，联系标题36–60px。这些是当前实现的流式范围，不是后续设计的永久上限。
- 首屏导语独立成块，正文16px，探索入口放在正文下方。作品说明14px、制作区及工具介绍15–16px、截图说明13–14px；手机保留正常行高与换行。目录视图也同步放大，避免画廊可读但目录仍过小。
- 片单首屏主标题使用更有分量的系统黑体，片名继续使用宋体；正文与主信息15–16px，辅助元信息12–13px，减少不必要的字距。桌面标题与导语并排，统计占完整一行，820px及以下恢复标题→导语→两列统计的阅读顺序。
- 片单原来的作品、简介、观看URL和三张封面保持。没有新增远程字体、运行时依赖或音视频请求。主站顶部导航、弹性文字、固定视频框与联系区原有功能保留。

复用评估参考：[sofish/typo.css](https://github.com/sofish/typo.css)（MIT）。其整套reset与当前站点样式重叠，因此只参考字体角色、行高和行长的处理思路，未复制源码或引入依赖。

## 验证

- 新增`tests/typography-smoke.py`：片单桌面导语应位于标题右侧的回归先红后绿；320／390／820／1191／1440五宽验证片单阅读顺序、文字不溢出、三个观看入口；主站另覆盖1920宽和中英两种语言、深浅色切换、标题与导语／画框不碰撞。
- 弹性标题4项、联系区4项、片单导航与语言往返2项、共享导航五宽双语1项、Pages打包1项通过。
- 旧视频框测试起始条件只接受`transform:none`，而既有视差脚本在零滚动位置保留`translateY(0px)`。用本轮改动前后的CSS各验证一次，两边都得到单位矩阵。测试改为接受`none`或单位矩阵，仍拒绝实际位移／缩放；所有媒体尺寸、逐帧位置和海报／视频同框断言保持。
- 视频框2项重新运行通过，覆盖四宽双语、五部影片切换／回首部、真实横竖片元数据、溶解、延迟和失败；本轮共16项相关检查通过，JS语法和Git空白检查通过。

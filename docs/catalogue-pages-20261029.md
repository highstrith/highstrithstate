# 作品分页与后页影片截图

用户认为20部全部连排容易视觉疲劳，要求分页，并从前两页看不到的作品中补几张到作品截图。本轮每页6部，共4页；后页选4部各截一张，保留原4张三维作品，共8张。

## 设计与实现

开工前参考 [GOV.UK Pagination](https://design-system.service.gov.uk/components/pagination/) 的页码、当前页语义、上一页／下一页和内容后放置控件。沿用本站原生HTML／JS，不复制组件代码或增加依赖。

步骤：补每页数量与完整覆盖失败断言 → 全量筛选后分页、保留原DOM → URL与键盘／语言／视图状态 → 选择真实后页画面并记录来源 → 八张截图与无脚本目录 → 回归、截图与本地提交。重点防止漏作品、只搜索当前页、页码重绘丢焦点、图片历史冲突及缩短页面后提前下载下方大图。

- pageSize=6，当前4页数量6／6／6／2，20个DOM节点保留。分类、搜索总数按匹配全集计算，显示范围与总数；页码aria-current，页首／页尾控件禁用，单页和空结果隐藏。
- 搜索／分类／清除条件回第1页，语言和目录视图保页。URL保留page/category/q/lang，刷新和新标签打开恢复同一组；翻页滚回作品区并聚焦标题。历史状态保留图片导航token。
- 先完成当前页布局，再创建截图与启用下方懒加载；隐藏页不会自动预览，离页留言区关闭，评论计数仍一次读取全部20部。
- 无脚本保留全部20部直接播放链接，静态站不新增服务或上传能力。

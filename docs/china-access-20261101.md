## 结论与边界

现站页面、目录与视频均从 `highstrith.github.io/highstrithstate/` 提供。已存在三档视频和响应式图片优化，关键字体、样式与动效库本地提供；评论 envId 为空，不加载 jsDelivr 上的 Twikoo。优先改善托管与分发链路。

当前网络单点实测复现视频传输缓慢和 TLS 超时，但不能据此断言全国所有运营商均被阻断，也不能保证更换某家境外服务后一定更快。

## 探测证据

macOS 系统配置了 127.0.0.1:7897 代理。以下 curl 均使用 `--noproxy '*'` 绕过显式代理；未验证是否仍有透明隧道或其他网络中间层。对照组 Google TCP 超时，百度正常。

| 请求 | 结果 |
| --- | --- |
| 百度 HEAD | 200，约 0.048 秒 |
| GitHub HEAD | 200，约 1.00 秒 |
| 现站首页 HEAD | 200，约 2.06 秒，其中 TLS 累计约 1.50 秒 |
| 机器人短片 web 版，Range 0–1048575 | 返回 206；20 秒仅收 572844 字节，约 28.6 KB/s，超时 |
| 另一部 web 视频，同样的 Range | TLS 连接约 5 秒超时，未收到正文 |

206 证明该请求支持按范围读取，不能把问题笼统归因于必须整片下载。HEAD 时间也不代表页面完整渲染耗时。

本地 21 条管理作品的三档衍生视频字段对应文件合计约 241.10 MiB，最大单文件 33,147,221 字节（约 31.61 MiB）。此为目录引用文件统计，不是首页下载量或完整发布产物大小。

## 可执行路线

### 先免备案：自有域名＋香港静态托管

1. 用户注册本人名下域名，并准备云账号；购买、实名认证和支付由本人完成。
2. 对香港线路先做电信／联通／移动的实际访问测试，再决定提供商。可以用静态服务器直接承载页面、图片与视频；若选轻量服务器，复用 Caddy 提供 HTTPS 和静态文件服务。
3. 从当前公开白名单生成独立部署目录，不上传原始媒体、本地管理服务或项目文档。先在新入口验证，原 GitHub Pages 保留。
4. 核对 HTTPS、目录首页、视频 Content-Type 与 Range/206、缓存更新、简历下载、reel/、双语和手机播放，合格后才作为主要分享入口。
5. 以 GitHub 保存源码并触发自动同步；发布失败不得替换最后可用版本。域名确定后再更新 canonical 和分享图片 URL。

香港托管仍属跨境链路；这是可先测试的免备案路线，不等同于大陆节点加速。费用取决于提供商、出网流量和访问量，本轮未购买或给出未经验证的价格。

### 国内访问优先：备案域名＋大陆对象存储／静态托管＋国内 CDN

若愿意办理备案，使用已备案域名接入大陆托管和国内 CDN，页面、图片与视频均从该链路分发。可用 COSCLI 同步白名单产物，不必重写现有静态前端。正式选择以账户、备案条件和流量成本为准。

- [EdgeOne Makers 当前免费版限制](https://pages.edgeone.ai/document/limits-and-quotas)列出单文件 25 MB；本站至少一部完整视频超过，不能未经处理直接整站搬入。若采用，应将大视频放对象存储，或另选托管方式。

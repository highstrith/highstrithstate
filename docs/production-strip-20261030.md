# 首页制作截图循环图带

用户要求首页正在制作的截图至少10张，从左向右滚动并循环。范围是既有首页制作区：沿用《未识之诺》15张真实素材，原9张在前、补齐独立记录页已有6张，不重新生成素材。独立制作页继续按资产6／分镜5／工作台4展示。

## 方案与实施步骤

开工前查阅 [GSAP 官方 seamlessLoop](https://gsap.com/docs/v3/HelperFunctions/helpers/seamlessLoop/) 的等速、可暂停与响应式循环思路。本站已有GSAP 3.15.0，简单的双组循环足够，不复制完整helper或增加包；原发行文件和许可头保持。

1. 新增真实浏览器行为断言，先复现旧首页只有9张、缺横向循环的失败。
2. `index.html`扩到15张，`studio.js`同步大图序列，CSS改为单行小图；保留纸白底、原字体与220px／手机180px图宽，完整构图不裁切。
3. 新增`assets/production-strip.js`，轨道从负一组宽度到0向右等速滚动，复制组与原组间距一致，首尾无空白。提供暂停／继续和上一张／下一张，点击仍是原大图弹窗。
4. 验证正常动效、首尾循环、暂停与双语、键盘与触屏、缩窗和减少动态／库失败／无脚本，检查大图返回及静态发布打包；同步文档并本地提交。

## 状态与边界

- 复制组不计入15张，`aria-hidden`且链接不重复进入Tab顺序；点击委托按原图索引打开，返回焦点交给原始链接。
- 悬停、原图键盘聚焦、弹窗、后台和离开制作区时临时暂停；手动暂停在切语言后保持。键盘聚焦隐藏位置时调整轨道，让原图出现在视口内。
- 图片只使用既有WebP缩略图，靠近制作区后预取本组，完整图按点击加载；15份PNG原件和归档不改动。
- 系统减少动态或GSAP不可用时不复制／自动滚动，保留原生横向浏览；无JavaScript的15张图可直接打开。首页原来图墙入场改由图带承担，独立页分组入场与大图过渡继续保留。
- 动态切换减少动态时，先清除transform，再将当前焦点图恢复到原生横滚视窗；切回自动时重新按该图取景。此问题由独立复核在390px实测发现，并先增加失败回归再修复。
- 作品分页、首页五部精选、8张作品截图和项目主次顺序保持。

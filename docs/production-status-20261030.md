# 制作中小状态动效

用户希望制作中文字稍微可爱，增加进度条之类的动效。此改动仅为首页及独立制作页《未识之诺》旁的状态视觉，保留原字号和内容：暖色小底、三个错峰轻跳圆点、下方往复生长的小横条，无真实完成百分比。

开工前参考 [Shoelace Progress Bar 的 Indeterminate 示例](https://shoelace.style/components/progress-bar#indeterminate)，采用不确定进度的表达；无需引入组件包或复制其代码。用本站现有CSS即可，原站点依赖不变。

步骤：检查双语更新与现有状态样式 → 将翻译属性留在内层纯文字，添加装饰圆点／轨道 → 共享CSS关键帧与减少动态 → 检查首页和独立页双语、320px排版、实际动画及原图带交互 → 同步固定文档、本地提交。

- 文字始终可读，圆点及小条均aria-hidden；不将装饰动画标记为实际progressbar。
- 圆点1.8秒轻跳，小条3.6秒缓缓往复；悬停状态或相关内容键盘聚焦时暂停。系统减少动态时立即停用动画、保留静态小条。
- 无JavaScript也能显示状态；翻译只改内层文字，动效节点不会被textContent清除。15张制作图带、大图浏览和原始素材不变。

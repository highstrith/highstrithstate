# 作品集统一横向封面

用户反馈中间两张竖片仍显奇怪，随后明确「还是换成全横屏」。本轮统一作品集和目录缩略图为16:9封面，桌面三列、平板两列、手机一列。标题、分类、简介统一在封面下方；完整播放保持原片比例。

沿用现有CSS Grid与封面，不新增依赖或重新制作媒体；此前已调研画廊实现，当前直接复用本站网格样式。删除原比例行宽计算，图片sizes继续按实际显示宽度更新，筛选／搜索／评论与图集返回机制保留。

原PNG／JPG、视频、优化资源和目录字段均不改动。竖片横向封面会裁去部分上下画面，点击播放器仍可完整观看。无脚本目录也保持网格列数和横向封面，避免旧span6规则撑出页面。

步骤：修改横向比例回归并确认旧布局失败 → 统一网格／预览和精简排版逻辑 → 实际查看四张封面确定取景 → 中英、尺寸、筛选、原比例播放、返回、静态打包和无脚本验证 → 本地提交供审核。用户明确认可前不push。

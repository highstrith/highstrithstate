# 近10天原作跳转榜

2026-11-02。用户最新决定：当前尚无本站放映资源，近期热门暂以原作链接跳转计算，替代上一版“等待本站有效播放统计”的口径。未来接通站内放映后再单独决定切换，历史跳转不会改称播放量。

本轮涉及现有访客API、片库与详情链接、榜单渲染和相关测试：先补真实HTTP及浏览器用例，再实现持久化计数、页面接线、回归与实看，最后本地提交。统计失败必须保留原作链接的原生打开行为。

## 计数规则

- 北京时间今天及前9个自然日，按本站原片观看链接的去重点击次数降序。
- 同一浏览器访客、同一作品、同一自然日最多一次。首页精选、卡片和详情的原作观看入口合并计数；打开作品详情、排名条目或单纯查看原平台评价入口不计。
- 支持正常点击、键盘激活和中键打开，不阻止原生外链／修饰键行为。右键菜单打开、复制链接、无脚本浏览不在此点击统计范围内。
- 页面明确显示“原作跳转”，不表示原平台播放量、实际观看或已成功加载原作。清除cookie或更换浏览器会成为另一访客，当前是轻量去重，不能宣称严格独立真人／防刷系统。

## 实现与数据

`server/framepick-reviews.cjs`沿用签名访客身份与同源保护，新增：

- GET `/api/framepick/outbound/summary`：`{metric:'outbound-clicks',windowStart,windowEnd,updatedAt,films:[{filmId,outboundClicks}]}`。
- POST `/api/framepick/films/:id/outbound`：先建立session，提交JSON空对象，返回`{counted:true/false}`；后端决定日期与次数，不接受前端提供次数或时间。

数据位于原站点根目录外的私密`~/.framepick/reviews/reviews.json`，新增可选outbound字段，旧版数据库缺少字段时兼容读取，原评价／签名身份保留。每条只含内部随机访客ID、作品ID与自然日，不存IP、昵称或原作完整URL。写入串行、原子替换，重复点击不重复写，正常新写入时清理窗口外记录；评价修改不会覆盖跳转记录，跳转也不消耗评价的写入冷却时间。

`reel/framepick-reviews.js`复用API配置与session Promise，成功记录后重新取榜单；请求代次保护迟到初始汇总，统计失败不伪造成功或拦截外链。`framepick-rankings.js`接收独立outbound-summary事件并校验统计口径／窗口／计数，缓存早到结果，沿用稳定排行链接与回焦。实时汇总允许服务端时间最多领先浏览器1分钟，避免数秒时钟偏差误判；超过24小时、明显未来或错误日期窗口仍不入榜。删除无人维护的`ranking-data.js`静态播放快照。

本地同源已接通；正式Pages仍需部署共享API，静态／file模式未配置时如实显示未配置，不用localStorage假装全站跳转数据。原有SameSite=Lax跨站部署与单进程文件存储边界继续有效，未发布网站。

## 开源评估与验证

HTTP测试覆盖10天边界、北京时间午夜、日去重、不同访客共享、无身份／错误来源／超大请求、旧数据库升级、并发、评价互不覆盖和重启保留。浏览器测试使用临时服务和私密临时数据，原作目标用隔离测试页承接，验证实际原生新标签打开、计数、重复去重、跨访客、刷新、失败不阻断和慢汇总不覆盖。

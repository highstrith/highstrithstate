# AI 影像聚合平台与搜片 AI 产品方案

日期：2026-11-02。状态：用户已确认产品方向；本文整理成可评审方案，新增细则为首版建议。页面、搜片任务、账户及支付均尚未实现。

## 1. 已确认的产品方向

建立一个持续发现优质 AI 视频的聚合平台。本站整理作品与原始来源链接，用户前往原平台观看。免费用户获得部分精选，VIP 解锁更多精选条目、原片链接和完整专题。原片本身免费，会员购买的是持续发现与整理服务。

专门配置一个搜片 AI，主动在抖音、快手、小红书等渠道寻找作品。优先查找较热门、传播较快的候选，同时允许高质量的非爆款作品进入片库。粉丝数不设门槛，不把“小众作者”设为平台的主定位。

核心原则：热度决定优先去看哪些作品，质量决定最终收录哪些作品。免费与 VIP 共用质量门槛。

本方案仅调整独立片单产品的后续方向。现有作品集和片单页面本轮均未修改，原有三部作品继续可用。片单旧文案中的“不排名、不打分”和“未来站内播放”在后续改版时按本方案替换。

## 2. 使用路径与页面

访客进入片库，选择分类和排序，查看影片卡片及推荐理由，再跳转原平台。VIP 在订阅有效期内访问完整精选库；到期后恢复免费范围。首版采用一个 VIP 档位。

| 页面 | 首版职责 |
| --- | --- |
| 发现首页 | 简短定位、搜索、精选区与作品列表，尽早展示真实内容 |
| 分类结果 | 主分类、题材标签、评分区间、来源、免费／全部筛选，支持组合 |
| 作品详情 | 作者、简介、时长、来源、评分依据、推荐理由、观看入口与相关作品 |
| 专题 | 按主题组织作品，免费专题及 VIP 完整专题 |
| 会员页 | 展示真实片库规模、开放样例、订阅权益与外部观看说明 |
| 待审核片库 | 接收搜片 AI 候选，查看证据、审核评分、选择免费／VIP后发布 |

首版主分类建议：剧情短片、系列短剧、商业广告、音乐影像、实验影像。科幻、武侠、奇幻等作为题材标签；写实、动画、水墨等作为视觉标签。不同维度分开，允许多标签。

默认按编辑精选展示，提供评分最高、最新收录排序。热度是发现线索，可在有可靠数据时附加热门标记，不能冒充质量评分。只有实际发布的作品才计入前台数量。

免费用户可完整查看免费条目及原片链接。首版建议VIP条目只公开封面、类型、评分与锁定状态，另选部分完整条目作为开放样例；片名、作者、完整说明与原片链接属于锁定详情。锁定详情及链接必须由服务端鉴权后返回，不能随静态HTML、搜索结果、JSON或站点地图公开。公开预览会透露有限线索，会员权益不承诺阻止用户在其他平台自行找到原片。

## 3. 搜片 AI 工作流

`发现候选 → 去重与核实 → 内容质量评估 → 待审核 → 发布 → 更新与维护`

1. **发现**：组合关键词搜索、平台可访问的热门内容、作者追踪和相关作品扩展。热门发现与非爆款探索都保留入口，不承诺覆盖平台全部内容。
2. **去重**：优先使用平台作品 ID 和规范原片链接。短链接解析后合并；跨平台同作品保留多个来源，同系列不同集保留独立条目并关联系列。不能确定是否重复时保留待核实状态。
3. **核实**：记录原作者、原始发布时间、原片链接、免费访问状态和核实时间。AI 制作属性依据作者披露或可信来源标记；无法确认时不补写模型和工具。
4. **评估**：能读取视频时结合画面与音轨评估；只有抽帧、文字或静音材料时明确覆盖范围。仅凭标题、封面、简介和互动量，不能生成正式质量评分。证据不足的候选进入待看片。
5. **审核与发布**：AI 输出分类、评分草稿、推荐理由和不足，运营审核后发布。首版保留审核步骤，不把搜索命中自动变成上线作品。
6. **维护**：追踪优秀作者与连载更新，复核失效和付费状态变化。失效链接标记、隐藏或替换为已核实的作者原始来源；不得用无关链接顶替。

搜片 AI 是一个独立的业务任务，可调用多个来源入口，不要求部署多个 Agent。首版先支持手动触发一轮，验证渠道和质量后再启用定时运行。当前未创建任何定时任务。

搜索频率、每轮候选上限、模型用量和重试次数均需可配置。某渠道登录失效、验证码、访问受限或超额时，记录失败与原因并结束该渠道本轮尝试，其余渠道继续；失败不等于没有新片，不做无限重试。

## 4. 评分与收录标准

首版展示审核后的编辑评分，使用10分制；AI草稿分和热度数据不直接成为公开评分。不制造社区平均分、观看人数或作品奖项。

| 维度 | 评价内容 |
| --- | --- |
| 创意与表达 | 想法是否明确，表达是否成立 |
| 画面与一致性 | 构图、光影、人物和场景连续性，生成瑕疵是否破坏体验 |
| 镜头与剪辑 | 景别、运镜和节奏是否服务表达 |
| 声音 | 配音、音乐、音效与画面的配合 |
| 完成度 | 是否完成该类型作品应有的表达，连载按当前收录集评价 |

剧情作品重点看叙事，实验影像重点看表达，广告重点看信息传达。适用维度与评分理由必须明确；静默作品不因没有配音就自动扣分。

首版运营建议：编辑评分达到8.0分且信息核实通过，才进入精选库。这个数值是待样本校准的初始建议，不是用户已确认的硬性阈值。先用一批实际看过的作品校准；后续修改评分规则需记录版本，不能拿涨粉和付费转化反向调整质量分。

每部作品提供一条具体推荐理由，并保留关键不足。严重影响观看的生成错误、明显未完成的片段或原始出处不明的候选，先留在待审核区。作品长短、作者粉丝量、是否爆款均不是独立淘汰理由。

## 5. 免费与订阅

免费用户查看开放精选并跳转原片；VIP访问完整精选、专题与订阅期内新增内容。两边都提供真实好作品，VIP扩大覆盖范围。

会员说明必须明确本站提供精选导航，原片在外部平台播放，可能需要平台登录。不宣传独家播放权或保证外部平台永远免费、无需登录。

会员价格、月／年周期、免费片库规模与对外更新承诺在真实供给和成本试运行后制定；本轮不编造价格，不创建收费资源、不绑定支付方式。正式收费前必须具备真实账户、服务端权限验证和可验证的订单状态，不能用浏览器切换VIP模拟收费上线。

## 6. 最小数据与状态

| 信息组 | 必须保留的内容 |
| --- | --- |
| 作品身份 | 内部ID、平台作品ID、片名、作者、主来源链接、替代原始来源、系列与集号 |
| 检索信息 | 主分类、题材与视觉标签、时长、原发布日、收录日 |
| 发现证据 | 发现渠道、查询词或作者入口、发现时间、来源URL、核实时间 |
| 热度快照 | 能核实的公开互动数据、采集时间；未知值留空，不跨平台直接比较绝对数量 |
| 质量证据 | 视频／音轨实际可读范围、分项评价、草稿分、编辑分、理由、审核人和规则版本 |
| 发布权限 | 候选／待看片／待审核／已发布／拒绝／失效，免费或VIP，发布记录 |
| 运行记录 | 本轮渠道、候选数、重复数、失败与原因、用量及结束状态 |

候选和已发布记录分开。去重后复跑不能重复新增；未经审核的内容不能进入正式目录，失效状态不能被下一轮搜索自动清除。

## 7. 复用调研与方案选择

制作本文前已查阅以下公开项目（核对日期2026-11-02）；本轮没有下载、复制或部署其源码：

| 项目 | 适配点与限制 | 结论 |
| --- | --- | --- |
| [FOSSRadar](https://github.com/wbfoss/fossradar) | MIT；有目录、分类与搜索结构，面向公开Git驱动目录 | 可参考信息组织；不能用公开数据文件承载VIP内容，不直接替换现站 |
| [Movary](https://github.com/leepeuker/movary) | MIT；偏电影观看记录与评分 | 可参考评分展示，完整系统与本站搜片需求不匹配 |
| [RSSHub](https://github.com/DIYgod/RSSHub) | 当前仓库标示AGPL-3.0；提供多源订阅聚合 | 可作为作者追踪候选；具体路由可用性、版本许可证与部署责任实施前逐项核对，不等于能覆盖三平台搜索 |
| [MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) | 声明支持多平台关键词及作者采集，同时明确禁止商业用途 | 不直接引入本付费产品；不把公开仓库误当作商业使用授权 |

可选路径：整体更换为目录模板；在现有独立片单旁补充搜片与会员服务；先全部靠人工维护。建议第二条：保留现有片单入口和视觉基础，独立验证搜片来源，再逐步接入发布与会员。避免为了分类页面先迁移整站，也避免只做界面而缺少内容供给。

## 8. 分阶段交付与验证

1. **内容供给验证**：搜片任务手动运行，覆盖热门与非爆款候选；每个可用渠道都保留真实搜索和核实证据。部分平台暂不可用时如实标记，不声称全部接通。
2. **片库浏览与审核**：使用核实后的真实内容实现分类、评分排序、详情、外链与审核。现有三部作品需要重新看片评分，不能虚构分数补齐界面。
3. **真实会员服务**：接入账户、服务端权限和支付，确认价格与更新承诺后再开放订阅。
4. **持续发现**：供给验证通过后启用定时搜片、失败记录和维护；只有实际配置并成功运行后才能报告自动化已启动。

关键验收场景：高热度但低质量不通过；低热度高质量可通过；只读到简介的内容不能正式评分；同一作品多次发现不重复；系列新集可以新增；免费和VIP使用同一质量标准；未订阅用户不能从接口或静态产物取得锁定内容；链接失效可追溯；某平台失败不阻塞其余来源，也不伪造成功。

试运行记录候选到收录的通过率、审核所需时间、重复和失效比例、分类覆盖与每条通过作品的发现成本。明确稳定供给后再作更新承诺，不为凑数量降低门槛。

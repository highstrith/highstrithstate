# 帧选片库页面实施计划

> 本轮在当前已隔离的Git worktree内执行。用户已明确要求按确认方案修改现有页面，按任务顺序在本会话实施。

**Goal:** 将独立片单改为可搜索、分类、筛选和查看详情的AI影像精选片库，呈现免费／VIP权益及真实开通状态。

**Architecture:** 静态HTML保留三部现有免费作品和原片外链；片单自身目录内的CSS／非模块JS负责布局、筛选、URL状态、收藏及详情。保留GitHub Pages与file模式，不新增依赖，不把静态页面伪装为会员后端。

**Tech Stack:** HTML、CSS、原生JavaScript、原生dialog；Python Playwright行为回归与Node Pages产物检查。

**Spec:** `docs/superpowers/specs/2026-11-02-ai-film-discovery-design.md`。本轮实现页面浏览部分，搜片、账户、收费服务不在本次页面改动内。

## 约束与设计

- 首批来源小红书、抖音、哔哩哔哩；既有3部都是抖音来源，其他来源无作品时展示真实空状态。X／YouTube不进入新片库。
- 当前三部无正式评分，显示待评；评分筛选排除待评作品，排序保留待评在末尾。无捏造评分、会员数或VIP影片。
- 全部现有作品保持免费。会员区明确筹备中，说明完整精选库权益；不提供假支付或浏览器切换VIP身份。
- 无JS时3部影片及外链可用；搜索／收藏等JS控件隐藏。深色独立产品风格不跟随个人主页修改。
- 文件：`reel/index.html`内容、`reel/framepick.css`样式、`reel/framepick.js`行为、`tests/framepick-library-smoke.py`行为验证；共享入口测试只更新已经批准的新标题断言，保留原入口及品牌断言。
- 色彩：影厅黑#101114、面板灰#191c21、纸白#eeeee8、雾灰#a2a7ad、原品牌橘#e0563c、会员金#d8b47b。字体采用现有系统黑体正文与宋体片名。左对齐、紧凑介绍、横幅精选、三列影片；手机单列，筛选自然换行。
- 不增加与内容无关的统计和装饰。沿用真实概念封面并标明非官方物料。只提供用户触发的细微动效，减少动态时关闭。
- 制作前重新查阅FOSSRadar（MIT）与CineList（GPL-3.0）；借鉴目录检索信息结构，沿用本项目原生代码和封面，不复制上游源码或迁移技术栈。

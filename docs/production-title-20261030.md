# 正在制作标题的省略号动效

用户澄清指的是「正在制作」标题文字本身，需要逐点出现的进度感。首页章节标题和独立制作页标题各增加固定宽的装饰三点，按0／1／2／3点循环，2.4秒一轮；保留上一轮小状态与15张图带。

开工前参考 [CSS Loaders](https://github.com/vineethtrv/css-loader) 的纯CSS加载动效实现方向，本站只需一个固定宽的文字span和离散clip-path关键帧，不复制库代码或引入依赖。

步骤：确认标题翻译与拆行逻辑 → 翻译属性移至内层文字、三点独立aria-hidden → CSS固定宽度与reduce静态 → 两页双语／320px／实际帧变化与可访问标题验证 → 本地提交。

导航、标题字号与原图带不变；点的出现不改变布局，屏幕阅读器不重复播报进度。此为低影响视觉调整，不新增专用测试文件。

验证：两页320px中英文无溢出、4次语言切换保留3个点；实际采样覆盖四种clip-path，标题几何宽度全程不变；无障碍名称精确为「正在制作」／「In progress」，reduce后无活动动画且三点静态，无JS错误。既有双语往返1项改为核对可访问标题名称（装饰点不应进入名称），通过3.325s；实际Pages打包1项、Git空白检查通过。桌面和手机截图见同名目录，已人工查看。
